# Changelog

## 0.1.0

First public release.

- Group windows of any app into shelves and switch between them with tabs
- Integration with Finder and Preview native tabs, including switching tabs by hovering
- Window snapping by dragging and keyboard shortcuts
- Space reserved for third-party Dock apps
- Automatic switching between Liquid Glass and a solid style
- Recovery of hidden windows after a crash
- Automatic updates with Sparkle
- English and Japanese
